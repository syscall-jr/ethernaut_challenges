# ethernaut_challenges

1. Installation of metamask from
    https://metamask.io/

2. Enabling the test network
    I used the sepolia test network throughout the task.

3. Getting test ethers.
    https://cloud.google.com/application/web3/faucet/ethereum

4. Get the new instance and confirm the transaction on metamask.

5. Setting up foundry
    curl -L https://foundry.paradigm.xyz | bash
    interact with the smart contract using cast. 
    cast is a command-line tool of foundry for performing Ethreum RPC calls.
    
This is the very basic steps to start solving the challanges in 
```https://ethernaut.openzeppelin.com```
